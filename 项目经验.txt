一、项目背景与需求
================================================================================

1. 核心需求：
   - 实现 Fujifilm FRGMT BW（藤原浩联名）黑白滤镜效果
   - 保持真实 Instax 相纸物理比例（72mm × 86mm）
   - 成像区域 62mm × 62mm 正方形
   - 所有页面（相机、预览、相册）显示完全一致

2. 关键挑战：
   - 黑白效果要有层次感，不能太黑或太白
   - 相纸边距要精确匹配物理规格
   - 成像区域必须是完美正方形
   - 照片不能变形、不能有黑边

================================================================================
二、问题分析与解决过程
================================================================================

【问题1】黑白滤镜效果过强
--------------------------
现象：
- 照片太黑，没有层次感
- 暗部死黑，亮部过曝
- 缺少中间色调

解决方案：
调整滤镜参数，降低对比度，增加亮度：

基础处理：
  contrast: 150% → 115%  # 降低对比度
  brightness: 95% → 102%  # 适当提亮
  grayscale: 100%

暗部处理：
  从 rgba(0,0,0,0.35) → rgba(0,0,0,0.08~0.15)
  使用细腻的渐变，避免死黑

颗粒噪点：
  强度：45% → 18%
  频率：0.95 → 0.75
  更细腻的颗粒感，营造静谧氛围


【问题2】相纸边距比例不一致
--------------------------
现象：
- 不同页面边距占比不同
- 放大预览时边距变宽
- 左右边距不相等

根本原因：
CSS百分比padding的问题：
  padding: 6% 7% 22% 7%  # 这里的百分比基于容器宽度
  但上下边距应该基于高度计算

最终解决方案：
使用绝对定位 + 精确百分比：

.polaroid {
  width: 260px;
  aspect-ratio: 72 / 86;  # 相纸比例
  position: relative;
}

.polaroid-image-area {
  position: absolute;
  top: 5.81%;      # 上边距 5mm / 86mm
  height: 72.09%;  # 成像区域 62mm / 86mm
  left: 50%;
  transform: translateX(-50%);
  width: calc(72.09% * 86 / 72);  # 确保正方形
}

关键计算：
  相纸：72mm宽 × 86mm高
  成像：62mm × 62mm正方形
  上边距：5mm = 5/86 = 5.81%
  下边距：19mm = 19/86 = 22.09%
  左右边距：5mm = 5/72 = 6.94%


【问题3】成像区域变形
--------------------------
现象：
- 人物看起来被压扁或拉长
- 照片宽高比不对
- 预览和相册里变形严重

尝试过的方案：
❌ 方案1：aspect-ratio: 1/1 + left/right定位
   问题：CSS计算冲突，导致宽度超出

❌ 方案2：top/bottom/left/right + aspect-ratio
   问题：超出相纸边界

❌ 方案3：object-fit: contain
   问题：有黑边，用户不接受

✅ 最终解决方案：
拍摄时就生成正方形照片：

// 拍摄时的代码
const size = Math.min(video.videoWidth, video.videoHeight);
canvas.width = size;
canvas.height = size;

// 居中裁剪为正方形
const startX = (video.videoWidth - size) / 2;
const startY = (video.videoHeight - size) / 2;
ctx.drawImage(video, startX, startY, size, size, 0, 0, size, size);

关键点：
1. 源头解决：拍摄时就是正方形
2. 显示时使用 object-fit: cover
3. 不会变形，不会有黑边


【问题4】相机镜头显示问题
--------------------------
现象：
- 镜头不是圆形
- 实时画面显示不正确

解决方案：
确保video标签使用正确的类：

<video id="camera-stream"
       class="absolute inset-0 w-full h-full object-cover"
       autoplay playsinline muted>

注意：镜头圆圈容器需要 overflow: hidden 和 rounded-full

【CSS核心代码】
-------------
/* 相纸容器 */
.polaroid {
  width: 260px;
  max-width: 70vw;
  aspect-ratio: 72 / 86;
  border-radius: 6px;
  position: relative;
}

/* 成像区域 - 62×62 正方形 */
.polaroid-image-area {
  position: absolute;
  top: 5.81%;           # 上边距 5mm
  height: 72.09%;       # 62mm / 86mm
  left: 50%;
  transform: translateX(-50%);
  width: calc(72.09% * 86 / 72);  # 确保正方形
  overflow: hidden;
  border-radius: 0;
  box-sizing: border-box;

  /* 黑白滤镜效果 */
  filter: grayscale(100%) contrast(115%) brightness(102%);
}

/* 照片显示 - 不变形 */
.polaroid-image-area img {
  width: 100% !important;
  height: 100% !important;
  object-fit: cover !important;
  object-position: center !important;
}


【黑白滤镜细节】
-------------
/* 基础处理 */
filter: grayscale(100%) contrast(115%) brightness(102%) saturate(0%);

/* 暗部处理 - 细腻层次 */
::before {
  background: radial-gradient(
    ellipse at center,
    transparent 50%,
    rgba(0, 0, 0, 0.08) 80%,
    rgba(0, 0, 0, 0.15) 100%
  );
  mix-blend-mode: multiply;
}

/* 颗粒噪点 - 静谧质感 */
::after {
  opacity: 0.18;
  background-image: url("data:image/svg+xml,...");  # base频率0.75
  mix-blend-mode: overlay;
}


【拍摄核心代码】
-------------
// 裁剪为正方形
const size = Math.min(video.videoWidth, video.videoHeight);
const canvas = document.createElement('canvas');
canvas.width = size;
canvas.height = size;

// 居中裁剪
const startX = (video.videoWidth - size) / 2;
const startY = (video.videoHeight - size) / 2;
const ctx = canvas.getContext('2d');
ctx.drawImage(video, startX, startY, size, size, 0, 0, size, size);

// 保存正方形照片
this.capturedImageData = canvas.toDataURL('image/jpeg', 0.95);

四、关键技术要点
================================================================================

1. CSS百分比计算的陷阱
   - padding/margin 的百分比基于父容器宽度
   - 解决：使用绝对定位 + 精确计算

2. aspect-ratio 的使用
   - 可以用来强制正方形
   - 但要避免与其他定位属性冲突
   - 最佳实践：固定一个维度，计算另一个维度

3. object-fit 的选择
   - contain：完整显示，可能有黑边
   - cover：填满容器，可能裁剪
   - 关键：源照片要是正方形，cover就不会有黑边

4. 拍摄时的裁剪
   - 摄像头画面通常不是正方形（4:3 或 16:9）
   - 必须在拍摄时就裁剪为正方形
   - 居中裁剪最好看

5. 滤镜效果的调优
   - 对比度不宜过高（115%左右合适）
   - 亮度略高于100%（102%）
   - 暗部用渐变而不是纯黑
   - 颗粒要细腻，强度适中

================================================================================
五、常见错误与避免
================================================================================

❌ 错误1：使用 padding 设置相纸边距
   问题：百分比基于宽度，上下边距不对
   解决：使用绝对定位 + 精确百分比

❌ 错误2：同时设置 left/right 和 aspect-ratio
   问题：CSS计算冲突，尺寸不对
   解决：固定宽度，用 left: 50% 居中

❌ 错误3：拍摄时用全尺寸画面
   问题：照片不是正方形，显示时变形
   解决：拍摄时就裁剪为正方形

❌ 错误4：使用 object-fit: contain
   问题：有黑边
   解决：拍摄时确保正方形，用 cover 填满

❌ 错误5：滤镜对比度太高
   问题：失去层次感，暗部死黑
   解决：降低对比度，增加亮度，使用渐变

================================================================================
六、性能优化建议
================================================================================

1. 预生成噪点图片
   - 使用 SVG data URI 而不是动态生成
   - 避免重复计算

2. CSS 硬件加速
   - 使用 transform 而不是 position
   - mix-blend-mode 利用 GPU 加速

3. 图片尺寸控制
   - 拍摄时裁剪为正方形，减少数据量
   - 使用适当的 JPEG 质量（0.95）

4. 避免 CSS 重计算
   - 固定容器尺寸，减少布局计算
   - 使用 will-change 提示浏览器优化

八、总结与心得
================================================================================

这次项目最大的收获：

1. 从源头解决问题
   - 显示变形？在拍摄时就裁剪为正方形
   - 比例不对？精确计算物理尺寸
   - 不要试图在显示层面修正源数据问题

2. 理解 CSS 的计算规则
   - 百分比基于什么计算很关键
   - 不同属性的组合会产生冲突
   - 简单直接的方案往往最好

3. 用户体验的细节
   - 黑边会让用户觉得不专业
   - 变形会让人不舒服
   - 所有地方必须完全一致

4. 调试方法
   - 先确认数据本身是否正确
   - 再检查显示逻辑
   - 一步步验证每个环节

5. 迭代优化
   - 先实现基本功能
   - 再根据反馈调整细节
   - 滤镜参数需要反复尝试
